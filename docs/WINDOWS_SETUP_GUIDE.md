# 🪟 Windows PC 처음부터 시작하기 (상세 셋업 가이드)

## 1. 시스템 요구 사양

- **운영체제**: Windows 10 (64-bit) 또는 Windows 11 (64-bit)
- **인터넷**: 유선 LAN 또는 안정적인 Wi-Fi 환경 (매일 아침 09:50~10:05 상시 연결 필요)
- **권한**: Windows 로컬 관리자 권한 (작업 스케줄러 등록 시 필요)
- **하드웨어**: RAM 4GB 이상, 디스크 여유 공간 2GB 이상

## 2. 1단계: Python 설치 (가장 중요)

프로그램 실행을 위해 Python 3.10 이상(Python 3.11 또는 3.12 권장)이 필요합니다.

### ① 파이썬 설치 프로그램 다운로드
1. 공식 웹사이트에 접속합니다: [Python 공식 다운로드 페이지](https://www.python.org/downloads/)
2. **Download Python 3.12.x** (또는 3.11.x) 버튼을 클릭하여 설치 파일(`python-3.12.x-amd64.exe`)을 다운로드합니다.

### ② 설치 시 필수 체크사항 ⚠️
다운로드한 설치 파일을 실행하면 아래와 같은 화면이 나타납니다:

> [!CAUTION]
> **설치 창 맨 아래에 있는 `[✓] Add python.exe to PATH` 항목을 반드시 체크해야 합니다!**  
> 이 항목을 체크하지 않으면 명령 프롬프트나 배치 파일에서 `python` 명령어를 인식하지 못해 프로그램이 실행되지 않습니다.

1. 창 맨 아래의 **`Add python.exe to PATH`** 체크박스를 클릭하여 선택합니다.
2. 상단의 **`Install Now`**를 클릭하여 설치를 진행합니다.
3. 설치 완료 창이 뜨면 **`Close`**를 누릅니다. (경우에 따라 `Disable path length limit` 버튼이 보이면 한 번 클릭해 주는 것이 좋습니다.)

### ③ 파이썬 설치 확인
1. 키보드의 `Win + R`을 누르고 `cmd`를 입력한 뒤 Enter를 누릅니다.
2. 열린 검은색 창(명령 프롬프트)에 다음 명령어를 입력하고 Enter를 누릅니다:
   ```cmd
   python --version
   ```
3. `Python 3.12.x`와 같이 버전이 출력되면 정상적으로 설치된 것입니다.

## 3. 2단계: 프로그램 파일 준비 및 폴더 배치

### ① 권장 설치 경로
프로그램 파일은 **한글이나 공백(띄어쓰기), 특수문자가 포함되지 않은 영문 경로**에 두는 것이 가장 안전합니다.

- ✅ **권장 경로**: `C:\cip` 또는 `C:\workspace\cip`
- ❌ **비권장 경로**: `C:\Users\홍길동\바탕 화면\새 폴더 (2)\cip` (한글 및 띄어쓰기로 인해 스케줄러 오작동 유발 가능)

### ② 폴더 생성 및 복사
1. `내 PC` ➔ `로컬 디스크 (C:)`로 이동합니다.
2. 빈 공간 우클릭 ➔ [새로 만들기] ➔ [폴더]를 누르고 폴더명을 `cip`로 지정합니다.
3. 다운로드받은 소스 파일 전체를 `C:\cip` 폴더 안으로 복사합니다.

폴더 구조 확인:
```text
C:\cip\
├── src/
├── docs/
├── config.json
├── main.py
├── run_automation.bat
├── register_scheduler.bat
├── unregister_scheduler.bat
└── requirements.txt
```

## 4. 3단계: 계정 정보 설정 (setup_account.bat)

프로그램이 로그인할 COSMAX eBiz 계정 정보를 설정합니다.

### 방법 A: 계정 설정 마법사 사용 (비IT 사용자 강력 추천 ⭐)
메모장을 열어 JSON 문법(따옴표, 콤마 등)을 고칠 필요 없이 클릭 한 번으로 안전하게 설정합니다:
1. `C:\cip\setup_account.bat` 파일을 마우스로 **더블 클릭**합니다.
2. 검은 창에 안내되는 질문에 따라:
   - `eBiz 아이디`: 본인 사번/아이디 입력 후 Enter
   - `eBiz 비밀번호`: 로그인 비밀번호 입력 후 Enter
3. 자동으로 안전한 `config.json` 파일이 생성됩니다.

### 방법 B: 메모장으로 직접 수정
1. `C:\cip\config.example.json`을 복사하여 `config.json`을 생성하거나, 기존 `config.json`을 메모장으로 엽니다.
2. `user_id`와 `user_pw`를 본인 정보로 변경하고 저장(`Ctrl + S`)합니다.

> [!NOTE]
> **🔒 Git 보안 관리 원칙**  
> 비밀번호가 들어있는 `config.json`은 `.gitignore`에 등록되어 있어 **Git에 절대 업로드되지 않고 내 PC에만 보관**됩니다.  
> Git에는 비밀번호 자리가 비어 있는 `config.example.json` 템플릿만 올라가므로 회사 동료들과 소스코드를 공유할 때 개인 비밀번호가 노출될 위험이 전혀 없습니다.

## 5. 4단계: 최초 의존성 설치 및 가상환경 구성

프로그램에는 최초 1회 가상환경(`venv`) 생성과 Playwright Chromium 브라우저 설치를 자동으로 수행하는 스크립트가 내장되어 있습니다.

### 방법 A: 원클릭 자동 설치 (추천)
1. 탐색기에서 `C:\cip\run_automation.bat` 파일을 마우스로 **더블 클릭**합니다.
2. 스크립트가 스스로:
   - `venv` 폴더 생성
   - `pip install -r requirements.txt` (Playwright, Holidays 라이브러리 설치)
   - `playwright install chromium` (전용 브라우저 다운로드)
   과정을 자동으로 완료합니다. (약 1~2분 소요)
3. 설치가 완료되면 자동으로 자동화 루틴이 1회 시작됩니다.

### 방법 B: 수동 설치 (명령 프롬프트 직접 입력)
네트워크 문제 등으로 직접 설치 과정을 눈으로 확인하고 싶다면:
1. `Win + R` ➔ `cmd` 실행 후 아래 명령어 순차 입력:
   ```cmd
   cd /d C:\cip
   python -m venv venv
   call venv\Scripts\activate.bat
   pip install -r requirements.txt
   playwright install chromium
   ```

## 6. 5단계: 정상 작동 확인 (화면 표시 테스트)

스케줄러에 등록하기 전, 브라우저 창이 실제로 열리고 로그인이 정상 작동하는지 직접 눈으로 확인합니다.

1. `Win + R` ➔ `cmd`를 입력하여 명령 프롬프트를 엽니다.
2. 아래 명령어를 입력하여 **주말/공휴일 무시 + 화면 표시(Headful)** 모드로 실행합니다:
   ```cmd
   cd /d C:\cip
   run_automation.bat --headful --force
   ```
3. **확인할 내용**:
   - Chromium 브라우저가 화면에 뜨는지 확인합니다.
   - COSMAX 로그인 페이지로 접속하여 아이디/비밀번호가 자동 입력되고 로그인되는지 확인합니다.
   - 13시, 14시, 15시 3개 탭이 열리며 입고예약 페이지에 접근하는지 확인합니다.
4. 테스트 후 `logs\` 폴더에 오늘 날짜(`YYYYMMDD`) 폴더가 생기고, 그 안에 `.log`, `.html`, `.png` 파일이 정상 생성되었는지 확인합니다.

## 7. 6단계: Windows 작업 스케줄러 자동 실행 등록

매일 아침 09:50에 컴퓨터가 스스로 켜져서 10:00 예약까지 처리하도록 스케줄러를 등록합니다.

1. 탐색기에서 `C:\cip\register_scheduler.bat` 파일을 찾습니다.
2. **마우스 우클릭 ➔ [관리자 권한으로 실행]**을 반드시 클릭합니다.
3. 검은 창이 열리며 작업 등록이 진행되고 다음과 같은 메시지가 나타납니다:
   ```text
   =======================================================
   [성공] Windows 작업 스케줄러 등록이 완료되었습니다!
   =======================================================
   * 등록된 작업 이름: CosmaxAutoReservation
   * 실행 주기: 매주 월, 화, 수, 목, 금 (주말 제외)
   * 실행 시간: 오전 09:50:00 (10:00 예약 오픈 전 자동 대기)
   * 실행 모드: Headless (백그라운드 자동 실행)
   ```
4. 아무 키나 눌러 창을 닫습니다.

> [!TIP]
> 작업 스케줄러 등록을 해제하고 싶을 때는 언제든 `unregister_scheduler.bat` 파일을 우클릭하여 **[관리자 권한으로 실행]**하면 원클릭으로 깔끔하게 삭제됩니다.

## 8. 7단계: 무인 실행을 위한 Windows 전원/절전 모드 설정

PC가 아침 09:50 이전에 **절전 모드(Sleep)**로 들어가 버리면 스케줄러가 정해진 시간에 실행되지 못할 수 있습니다. 무인 PC의 전원 설정을 반드시 점검하세요.

### ① 절전 모드 해제
1. `시작` ➔ `설정(톱니바퀴)` ➔ `시스템` ➔ `전원 및 배터리` (또는 `전원 및 절전`)로 이동합니다.
2. **화면 및 절전**:
   - **화면 끄기**: `15분` 또는 원하는 시간 설정 가능 (화면만 꺼지는 것은 괜찮음)
   - **절전 모드 (PC를 절전 상태로 전환)**: **`해당 없음(안 함)`**으로 반드시 설정!

### ② 작업 스케줄러 '컴퓨터를 깨워 이 작업 실행' 확인
1. `Win + R` ➔ `taskschd.msc` 입력 후 Enter를 누릅니다.
2. 왼쪽 메뉴에서 **`작업 스케줄러 라이브러리`**를 클릭합니다.
3. 목록에서 **`CosmaxAutoReservation`**을 찾아 마우스 더블 클릭합니다.
4. **`조건`** 탭을 클릭합니다.
5. `전원` 항목의 **`[✓] 이 작업을 실행하기 위해 절전 모드 종료`**에 체크되어 있는지 확인하고(권장), 노트북인 경우 `컴퓨터의 AC 전원이 켜져 있는 경우에만 작업 시작` 체크를 해제하거나 항상 전원 어댑터를 연결해 둡니다.
6. [확인]을 눌러 저장합니다.
